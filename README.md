# 노트북에 Miniconda 설치 방법

Miniconda 설치 및 환경 구성 가이드

## 1단계: Miniconda 다운로드 및 설치

다운로드: 구글에 'Miniconda'를 검색하거나 아래 공식 링크에 접속합니다.

링크: https://docs.anaconda.com/miniconda/

파일 선택: Miniconda3 Windows 64-bit 버전을 다운로드합니다.

설치 진행 (Installer): 다운로드한 파일을 실행하고 Next를 누르며 기본값으로 설치하되, 아래 옵션 화면에서 반드시 체크를 확인합니다.

Clear the package cache upon completion (설치 완료 후 임시 파일 삭제)

나머지 옵션은 기본 상태(Recommended)로 두고 Install을 누릅니다.

## 2단계: 설치 확인

윈도우 시작 메뉴(또는 검색창)에서 Anaconda Prompt (miniconda3)를 찾아 실행합니다.

터미널 창 맨 왼쪽에 (base)가 표시되면 정상 설치된 것입니다.
